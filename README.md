# 📍 BaseCoords

No need to write down your coordinates on paper or clutter your gallery with screenshots.  
With **BaseCoords**, easily save and access your locations anytime. Everything is stored cleanly on the server!

---

## ✨ Features

- 💾 **Instant Save**: save your current position with a custom base name.
- 💬 **Quick Display**: view coordinates directly in the chat.
- ⚡ **Lightweight & Fast**: zero server lag or performance overhead.
- 🔒 **Clean Storage**: data is stored safely server-side.

---

## 💻 Commands & Usage

| Command | Description |
| :--- | :--- |
| `/setbase <name>` | Saves your current location with the specified base name. |
| `/base <name>` | Displays the coordinates of the base in chat (supports tab completion to list your bases). |
| `/deletebase <name>` | Deletes the specified base and its coordinates. |

---

## 🚀 Installation

1. Download the **BaseCoords** `.jar` file. (Clone the repository and compile the project using Maven)
2. Drop it into your Minecraft server's `plugins/` folder (Paper, Spigot, Purpur...).
3. Restart or reload your server.
4. Players can now use `/setbase`, `/base`, and `/deletebase`!
